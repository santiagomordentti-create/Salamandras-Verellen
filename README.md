# Salamandras Verellen

Sitio de una sola página (`index.html`, con HTML, CSS y JS adentro) para Verellen Fuegos, Tandil. El hero usa de fondo un video en loop (`assets/hero-loop.mp4`) y muestra una imagen fija (`assets/hero-bg.jpg` o `assets/hero-bg-mobile.jpg`) si el usuario tiene activado "reducir movimiento".

## Pendientes

Estos textos están marcados entre corchetes en el HTML:

- [ ] Provoleteras: modelos y medidas
- [ ] Discos: modelos y medidas
- [ ] Confirmar la zona de instalación y envíos (sección Instalación)
- [ ] Foto del taller o de la familia Verellen (sección Nosotros)
- [ ] Días y horarios de atención (sección Contacto)

También faltan las fotos de producto: cada placeholder `FOTO · ...` dice cuál va.
